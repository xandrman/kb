# AGENTS.md

Этот файл — корневая инструкция репозитория. Она действует всегда и дополняется вложенными `AGENTS.md`.

## Вложенные инструкции

Перед изменением или созданием любого файла определи каталог верхнего уровня, к которому он относится, и прочитай соответствующий `AGENTS.md` **до** начала работы. Правила вложенного файла имеют приоритет над корневым в пределах своего каталога.

| Область работы | Обязательно прочитать |
| --- | --- |
| `backend/**` | `backend/AGENTS.md` |

Если затронуто несколько областей — прочитай все соответствующие файлы. Если в каталоге появился новый `AGENTS.md`, которого нет в таблице, — читай его тоже и добавь строку в таблицу.

## Техническое задание

Техническое задание проекта располагается по пути `docs/SRS.md`. Необходимо строго следовать ему при разработке.

## Backend

Разработка backend ведётся с помощью Laravel Sail в директории `backend/`. Инструкции по стеку, командам Sail, Artisan, Pint и PHPUnit — в `backend/AGENTS.md`; читай его перед любой правкой внутри `backend/`.

`backend/CLAUDE.md` — копия `backend/AGENTS.md`, генерируемая Laravel Boost. Оба файла перезаписываются командой Boost, поэтому ручные правки вносить в них не следует: проектные договорённости по backend записывай в `backend/.ai/rules/`.

## Infra

Инфраструктура (Terraform, nginx, php-fpm, стек наблюдаемости) — в `infra/`. Отдельного `AGENTS.md` там пока нет.

## Документация

- `docs/SRS.md` — техническое задание.
- `docs/adr/` — архитектурные решения. ADR неизменяемы: принятый ADR не правится, вместо этого создаётся новый с частичным или полным замещением. ADR ссылается только на ТЗ и другие ADR.
- `docs/Конспекты/` — рабочие заметки, на них нельзя ссылаться из ADR.
